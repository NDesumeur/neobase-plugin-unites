# Unités

Convertisseur d'unités pour NeoBase : longueurs, masses, volumes, surfaces, températures, vitesses,
données, monnaies (taux du jour) et bien d'autres.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Unités → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
